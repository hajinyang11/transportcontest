# 2025년 연중 전날 안내: 운영 수준 변화와 날씨 추가 비교

2026-10-22, 연중 새 예측 결과 확인 전 작성. 사용자는 2024년보다 2025년 대기가 감소한 점을 반영하고 7~8월을 포함해 날씨 제외/포함을 비교하도록 요청했다.

## 판단 질문

최근 대기 수준에 적응한 같은 모형에서, 미리 알 수 있는 강수량·기온·날씨 코드를 추가하면 2025년 전체 및 7~8월의 대기 안내가 개선되는가? 대표값의 평균 오차와 안내 상한의 실제 포함률·과다 여유를 구분한다.

## 자료와 표본

- 2024·2025년 정상 탑승 완료 즉시호출 유사 기록과 JMA MSM의 동일한 48시간 선행 예보를 사용한다. 2023년 탑승은 과거 최근 실적 입력을 만들기 위한 2023년 11~12월만 사용하며 모형 학습 정답으로 추가하지 않는다.
- 두 연구 지역은 기존 이화동(60_127)·신촌동(59_126) 기준 격자에 연결한 서울 행정동 이름 조합이다. JMA의 해당 대표 좌표 예보를 연결하며 KMA/JMA 격자가 같은 것은 아니다. 전 서울 평가로 일반화하지 않는다.
- 기존 2025년 KMA 자료 가용 여부로 표본을 제한하지 않고 원래 준비한 정상 탑승 내역에서 해당 지역을 다시 추출한다. JMA 세 항목이 모두 있는 학습·평가 기록만 모든 비교 방식에 공통 사용한다. 제외 건수를 기록하고 결측을 0으로 채우지 않는다.
- 대상은 접수부터 승차까지이며 취소·미탑승 및 실제 병원 지각은 평가하지 않는다.

## 연도 간 대기 수준 변화 처리

2025년 전체 평균 감소 폭을 미리 알아 모든 예측에서 빼지 않는다. 미래 정답을 쓰게 되기 때문이다.

1. 2023년 11월부터 2025년 말까지 이어지는 최근 7/28/56일의 완료 건수·대기 평균·60분 초과 비율을 입력한다. 1월 1일에도 최근 이력을 끊지 않는다. 서울 전체 자료로 구별·인접 호출시간·전체 실적을 만들며 각 호출일 전날 00시 이전에 완료된 것만 쓴다.
2. 매달 이미 완료된 과거 자료로 재학습한다.
3. 주 비교는 최근 자료 가중치를 적용한 모형 두 개(날씨 제외/포함)다. 학습 사례의 가중치는 요청일 기준 180일 반감기이며 결과에 맞춰 조정하지 않는다. 이는 운영 환경 변화에 대응하기 위한 설계 가정이지 최적 반감기라는 주장이 아니다.
4. 동일 가중치 모형과의 2×2 비교로 균등 학습 두 개도 함께 계산한다. 날씨 효과와 최근 가중치 효과를 분리한다.
5. 모든 방식에 같은 과거 오차 기반 일별 보정 규칙을 적용한다. 대표값은 최근 28일 잔차 중앙값, 90% 목표 경계는 최근 56일 잔차 순위로 보정한다. 출발 구×시간대에 100건·5일 이상이면 해당 집단, 아니면 시간대, 전체로 후퇴한다. 보정에 날씨 조건을 넣지 않아 날씨 입력 효과를 분리한다. 원래 예측의 오차도 별도 제시한다.

## 방법과 시간 순서

- 비교: 최근 90일 지역×요일×시간 단순 표, 균등 학습 AI 두 개, 180일 반감기 AI 두 개. 단순 표는 셀 30건 미만이면 요일×시간, 전체로 후퇴한다.
- AI는 기존 HGB 분위수 회귀 구조와 기본 설정을 유지한다. 모델 크기 후보 leaf15/leaf31만 2024년 7~8월의 순차 예측에서 선택한다. 최근 가중치 적용 날씨 제외/포함의 합친 중앙값 절대오차가 작은 후보를 선택하고 전체 방식에 같은 크기를 쓴다. 2025년 결과로 설정이나 가중치를 선택하지 않는다. q0.5·q0.9를 별도로 학습한다.
- 일반 입력: 호출 시각·요일·월 주기·출발 구/동·연구 지역·최근 실적. 날씨 입력 추가: log1p(48시간 선행 강수량), 같은 예보의 기온·WMO 날씨 코드. 공휴일 workday는 연도별 같은 원자료가 없으므로 제외한다.
- 학습은 2024년 1월부터 시작하며 해당 예측 월 첫날−1일 00시 이전에 완료된 결과만 허용한다.
- 2024년 11~12월을 보정 준비용으로 순차 예측한 뒤, 2025년 1~12월을 모두 순차 예측·평가한다. 7~8월을 설정 선택에 재사용하지 않는다.
- 예보의 대상 시각 H는 직전 한 시간 H-1~H 강수량이다. 호출 시각 내림+1시간과 연결한다. `_previous_day2`는 API 설명상 48시간 선행 값으로 정확한 호출−24시간보다 기준 시각이 최소 23시간 이르다. 원 실행·배포 시각을 직접 받은 자료와는 구분한다. 최신 24시간 선행 예보의 효과를 그대로 측정한 것은 아니다.

## 평가

- 주 집단: 2025년 전체, 7~8월 전체, 7~8월 비예보, 7~8월 비예보 15~21시. 연간 비예보, 15~21시, 의료 목적, 월별·지역별은 보조다.
- 비예보는 강수 예보가 0보다 크고 WMO 눈 코드(71/73/75/77/85/86)가 아닌 경우로 정의한다. 해당 시간 내 강수 합과 시간 끝 날씨 코드의 조합이며 실제 비 관측과 같다고 하지 않는다. 겨울의 눈 집단도 별도로 표시한다.
- 실제 비 관측 집단은 기존 AWS의 해당 출발 구·호출 시간 rain_next가 있는 경우에 한해 사후 집단 구분에만 사용한다. 누락을 무강수로 처리하지 않으며 학습·보정에는 넣지 않는다.
- 평균절대오차, 평균편향, 대표값보다 20분 이상 긴 비율, 경계 포함률, 경계보다 20분 초과, 평균 안내 경계와 과다 여유를 함께 보고한다.
- 같은 평가 정답에서 포함률 90%를 맞춘 여유 효율은 사후 진단으로 구분한다. 미래 90% 보장으로 주장하지 않는다.
- 날짜 단위 이동 7일 블록 1,000회 재표집으로 차이의 범위를 보고, 작은 비예보 집단의 날짜 수를 함께 제시한다. 7~8월 집단은 해당 62일 안에서만 날짜 블록을 만든다.
- 2025년 자료는 이전에도 탐색했으므로 완전히 새로운 미래 검증이 아니다. 현재 실험의 설정 선택·월별 학습·보정에는 그 시점 이후의 정답을 사용하지 않는다.

## 판단 기준

날씨가 평균 오차를 줄여도 경계 초과가 늘거나 같은 신뢰도의 여유가 개선되지 않으면 그 한계를 함께 보고한다. 최근 가중치가 항상 낫다고 전제하지 않는다. 7~8월 또는 비예보에서 이익이 없으면 계절이나 데이터 부족을 이유로 효과를 만들어 설명하지 않는다. 실제 외출 성공·병원 정시 도착·탄소 감소는 이 비교로 입증하지 않는다.
