# 전날 예상 탑승시각 범위 검증 계획

작성: 2026-10-22. 아래 설계를 새 구간 예측 결과 산출 전에 고정한다.

## 사용자 질문과 검증 대상

“내일 이 지역에서 오후 2시에 신청하면 몇 시부터 몇 시 사이에 탈 수 있는가?”를 지원한다. 호출 예정시각에 접수→승차 대기 하한·상한을 더하면 탑승시각 범위가 된다. 범위 폭은 두 표현에서 같다. 기존 중앙값·90분위 상한의 포함률은 양쪽 구간의 포함률이 아니므로 재사용하지 않는다.

- 기존 연중 비교와 같은 2025년 정상 탑승 완료 113,776건. 47개 동 조합, 두 대표 예보 격자에 한정.
- 2025년은 이전에 탐색한 내부 개발 검증 기간이다. 새로운 미사용 시험자료라고 표현하지 않는다.
- 취소·미탑승·실제 차량 도착시각과 일정 결과가 없으므로 전체 호출의 성공률, 기존 앱 대비 성능, 실제 지각 감소를 주장하지 않는다.

## 사전 고정 비교

1. 단순 통계표: 기존과 같은 최근 90일 구·요일·시간별 분위수. 같은 표본 부족 기준(30건)과 요일·시간/전체 fallback 적용.
2. AI: 기존 recent_weather의 특성, 월별 재학습, 반감기 180일, 2024년에서 선택한 고정 HGB 설정 사용. 새 하한 5·10분위와 상한 95분위만 학습하며 기존 90분위와 중앙값은 재사용한다. 새 성능을 보고 모형 설정을 선택하지 않는다.
3. 목표 포함률: 중앙 80%(10~90분위), 중앙 90%(5~95분위). 대표 예측 중심 ±15·30·45분(하한 0으로 제한)이라는 단순 고정 폭 진단도 두 방식에 동일하게 적용한다. 고정 폭은 최단 구간을 최적화한 결과가 아니다.

## 시간 순서와 범위 보정

- 2024년 11~12월을 보정 준비 이력, 2025년 1~12월을 평가로 둔다.
- 월별 학습은 해당 월 시작 전날 0시보다 이전에 탑승 완료한 자료만 사용한다.
- 각 목표일 전날 0시보다 이전에 완료된 직전 56일의 과거 예측 잔차로 하한·상한을 각각 보정한다. 과거 정답으로 다시 학습한 fitted 값이 아닌 당시 월별 예측값을 사용한다.
- 구×시간대 100건·5일 이상, 미달 시 시간대, 전체 순으로 공통 fallback 적용. 분위수 순서통계의 하한 floor((n+1)p), 상한 ceil((n+1)p)를 사용한다. 확률 보장은 주장하지 않는다.
- 하한은 0 이상 및 기존 보정 중앙값 이하, 상한은 기존 보정 중앙값 이상으로 제한한다. 교차하는 원시 분위수는 중앙값과 인접 분위수의 순서를 복구한다. 90% 범위가 80% 범위를 포함하도록 사전 정의한 외향 확장만 허용하고 빈도를 보고한다.
- 실제 관측 우천은 사후 평가에만 쓰며 모형·보정 그룹에 넣지 않는다.

## 보고 지표

- 실제 포함률, 하한보다 이른 비율, 상한보다 늦은 비율, 상한보다 20분 이상 늦은 비율.
- 범위 폭의 평균·중앙값·90분위, 폭 30·60·90분 이하 비중.
- Interval score: 폭 + (2/alpha)×구간 밖 이른/늦은 오차. 같은 목표 포함률에서 작은 값이 좋다. 사용자 가치의 대리지표이며 실제 효용 아님.
- 전체, 7~8월, 7~8월 비예보 15~21시, 실제 우천 15~21시 부분표본을 우선 보고. 구·월·주야별 편차도 저장.
- 실제 동일 포함률로 사후 조정하는 방법을 주 결과로 사용하지 않는다. 목표가 같아도 실제 포함률이 다르면 폭만으로 우열을 판정하지 않는다.
- 범위 폭의 임계값은 계획에 필요한 시간을 논의하기 위한 예시이며 인터뷰로 검증한 수용 기준이 아니다. 좁은 범위만 선택해 전체 서비스의 성능처럼 제시하지 않는다.
- 날짜 상관을 고려한 7일 이동 블록 1,000회 재표집으로 포함률·폭 및 방법 간 차이의 불확실성을 계산한다. 우천은 적은 날짜의 부분표본임을 명시한다.

## 독립 확인

전체 행의 접수·승차와 기존 평가 표본 일치, 학습/보정 마지막 완료시각 < 정보 마감 ≤ 예측 의사결정시각, 범위 순서·유한값, 집계 재산출, 고정 폭 상한, 관측 날씨의 입력 제외를 확인한다. 비용·정시 도착·이용자의 계획 가능성을 실측한 결과와 혼동하지 않는다.
