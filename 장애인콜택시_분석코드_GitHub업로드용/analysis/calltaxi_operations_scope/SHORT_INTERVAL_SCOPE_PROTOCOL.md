# 30·45분 이내 예상 탑승 범위: 적용 범위 확인 계획

작성: 2026-10-22. 분석 대상은 기존 전날 구간 예측의 2025년 113,776건이다.

## 목적과 선행 확인

이용자가 지정한 30·45분 폭에서 약 90%의 실제 포함률을 보이는 지역·시간 조건과 전체 이용 중 적용 비중을 확인한다. 새 모형 학습은 하지 않는다. 분석 설계를 정하기 전에 전체 폭 분포의 기초 집계에서 AI의 45분 이하 구간이 44,472건(39.09%), 포함률 90.30%임을 확인했다. 아래 지역×시간 선택 및 후반기 확인은 아직 수행하지 않은 상태에서 정한다. 2025년 전체는 이전 분석에서 이미 탐색했으므로 독립적인 미사용 시험자료라고 표현하지 않는다.

## 1 주 비교: 결과를 보지 않는 사전 적용 규칙

- 기존 90% 목표 하한·상한의 예측 폭이 30분/45분 이하일 때만 ‘해당 폭 안의 계획 참고정보’로 표시하는 규칙을 고정한다. 범위를 사후에 줄이거나 실제 탑승을 본 뒤 이동시키지 않는다.
- 이 규칙은 전날 계산한 예측 폭으로 판단할 수 있다. 이후 실제 포함률은 별도로 평가한다.
- 전체·상반기(1~6월)·하반기(7~12월)의 포함률, 평균/최대 폭, 이른/늦은 이탈, 건수와 분모 대비 비중을 보고한다.
- 단순 통계표도 같은 폭 제한 규칙으로 평가한다. 각 방식이 선택한 사례가 다를 수 있으므로 자체 적용 집합끼리 정확도 우열을 단정하지 않는다. 공통 선택 집합과 AI 선택 집합의 동일 사례 비교도 별도로 남긴다.

## 2 지역・시간별 탐색과 이후 기간 확인

- 지역 단위는 출발 구, 시간은 1시간대(예: 10:00~10:59)다. 구 전체가 아니라 기존 두 예보 격자에 연결된 47개 동의 부분범위다.
- 상반기에서 AI 폭 제한을 통과한 표본 100건 이상・20일 이상・실제 포함률 90% 이상인 구×시간을 후보로 선택한다. 7월 1일의 전날 의사결정 이전에 고정할 수 있도록 실제 후보 선택에는 6월 30일 0시 이전에 탑승 완료한 기록만 쓴다. 선택에는 하반기 결과를 사용하지 않는다.
- 후보 목록을 고정한 뒤 하반기에 같은 구×시간 및 같은 폭 제한 규칙을 적용한다. 하반기에 잘 맞은 후보만 다시 묶어 ‘미리 정한 정책’의 성과처럼 제시하지 않는다.
- 하반기 표본 100건 이상・20일 이상을 확인 규모 기준으로 둔다. 후보 전체의 실제 포함률과 적용 비중을 먼저 보고하고 개별 후보도 모두 저장한다.
- ‘약 90%’ 해석은 88% 이상(2%p 허용)을 검토용 가정으로 함께 표시하되, 90% 이상인 개수도 구분한다. 88%가 사용자가 수용한다고 검증한 기준은 아니며 시범 운영 기준으로 확정하지 않는다.
- 날짜별 상관을 고려한 7일 이동 블록 1,000회 재표집으로 후보 전체·개별 후보의 포함률 변동을 확인한다. 95% 하한이 90% 미만이면 90% 신뢰도 보장을 입증했다고 쓰지 않는다.
- 요일군(평일/주말), 월별, 비예보 및 실제 우천 부분표본도 보조 확인한다. 이 결과로 후보를 추가 재선택하지 않는다.

## 3 분모와 정책 해석

- ‘전체 이용’의 주 분모는 연구 범위 내 정상 탑승 완료 113,776건이며 하반기는 해당 기간의 전체 완료 건수다. 모든 서울 호출·이용자 수·취소 포함 이용 성공률로 일반화하지 않는다.
- 전체 이용의 어느 비중에 좁은 범위를 제공할 수 있는지와, 그 제공 건들 중 실제 탑승을 포함하는 비율을 구분한다. 전체 이용의 90%에 적용된다는 뜻이 아니다.
- 조건별 결과가 충분히 의미 있으면 보고서 초안의 핵심 근거·방법·정책 적용 조건을 갱신한다. 이때 기존 단측 지연 상한의 포함률과 새 양측 구간의 포함률을 명확히 구분한다.
